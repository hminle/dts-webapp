### Findings worth remembering

- Vercel strips `s-maxage` / `stale-while-revalidate` from the client-facing header; prove
  caching with `x-vercel-cache: HIT`, not the header text.
- FastAPI answers `HEAD` with 405 — use `GET` (`curl -s -o /dev/null -D -`), not `curl -I`.
- shadcn's sidebar sets a `sidebar_state` cookie on toggle; the privacy page names it.
- zsh: never use `path` as a loop variable (it is tied to `$PATH`).
- `cf r2 objects get` has no `--file`; download snapshots from the public r2.dev URL.
- `vercel curl --deployment <url>` reaches protected previews (it created a bypass token).
