    Part 3

    Developer briefing

    Goal: every financial formula has a direct unit test; each formula's wording lives in frontend/src/features/methodology/formulas.ts; the worked examples live in worked-examples.json beside it and are asserted by backend/tests/test_formula_examples.py through the real functions. The Methodology page and a FormulaHint popover both render from the registry. No formula, API response or OpenAPI contract changes.

    Key decisions

    • Test functions, not routes. API tests exist; these call the formula functions on small in-memory DuckDB files built by the real schema code.
    • Pin, don't fix. Surprising behavior is recorded and explained: calendar-date charts drop a date the other year lacks, while category cards fall back to the latest earlier statement.
    • The examples file sits in the frontend. Vercel builds the web service from frontend/, so the page must own the file; the backend test reads it by repo path, which CI checks out in full.
    • Popover over tooltip. It opens on tap, holds a link, and is keyboard reachable. On a category card the name is the button that opens the dialog (stretched over the card), and the hint sits beside it, so the two never nest and a tap on the hint never opens the dialog.
    • Code wins over the reference docs. The reference names Social Security components that the code no longer uses; copy is written from categories.py, and a test checks the names.

    Phase order

    0 Setup ✓→1 Backend formula tests ✓→2 Registry & Methodology ✓→3 In-context hints ✓

    Risks

    • A test exposes a real bug. Phase 1 pins current behavior with a comment and records it; the fix goes on its own fix/ branch so the explanation and the behavior change together.
    • Social Security FYTD is down 26% at day 12 (69,492 vs 94,379). Confirmed as the benefit payment calendar: FY2026's first 12 days held payments on Oct 3, 8 and 15; FY2027's only on Oct 2 and 14. The Methodology lists it under Known limits.
    • Rounding at billions. toFixed shows 16.755 as 16.75, so the arithmetic examples are shown in millions.
